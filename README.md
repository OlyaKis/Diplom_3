Этот проект содержит автоматические тесты для веб-приложения Stellar Burgers в рамках дипломного задания.
Тесты покрывают основные пользовательские сценарии: восстановление пароля, работу с личным кабинетом, оформление заказа и ленту заказов.
Архитектура реализована по паттерну Page Object Model.
Тесты поддерживают кроссбраузерное выполнение (Google Chrome и Mozilla Firefox) и генерируют Allure-отчёты.

Структура проекта:
-pages/ — Page Object классы для всех ключевых страниц приложения
-locators/ — отдельные файлы с локаторами для каждой страницы
-tests/ — автотесты, сгруппированные по функциональности
-utils/ — вспомогательные классы и методы (API, тестовые данные и др.)
-requirements.txt — зависимости проекта

Что протестировано:

Восстановление пароля
*Переход на страницу восстановления
*Ввод почты и клик по кнопке "Восстановить"
*Проверка активности поля пароля при клике "показать/скрыть"

Личный кабинет
*Переход по клику на "Личный кабинет"
*Переход в раздел "История заказов"
*Выход из аккаунта

Основной функционал
*Переход по клику на "Конструктор"
*Переход по клику на "Лента заказов"
*Открытие и закрытие всплывающего окна ингредиента
*Увеличение счётчика ингредиента при добавлении
*Оформление заказа залогиненным пользователем

Лента заказов
*Открытие деталей заказа во всплывающем окне
*Заказы пользователя видны в ленте
*Проверка увеличения счётчиков "Выполнено за всё время" и "Выполнено за сегодня" после заказа
*Появление номера заказа в разделе "В работе"
